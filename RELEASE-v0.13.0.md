# Gapsy CRM v0.13.0: відпустки і лікарняні

## Що нового

- **Мій баланс** на `/leave` і на Головній: скільки робочих днів відпустки й лікарняних лишилось.
  - Залишок = річний ліміт − години, затрекані в ClickUp на задачах «GPS | Vacation» і «GPS | Sick Days» − погоджене, але ще не внесене в ClickUp.
  - CRM лише **читає** ClickUp і нічого там не змінює. Години оновлюються автоматично не частіше ніж раз на 10 хв; кнопка «Оновити з ClickUp» робить це одразу.
- **Ліміти:** відпустка 120 год (15 днів) на рік; лікарняні 40 год + 8 год за кожен повний рік роботи. Admin може поставити людині свій ліміт.
- **Запит:** тип, дати, коментар. Дні робочі: субота, неділя й свята компанії не рахуються; 1 день = 8 год, для одного дня можна вказати менше годин. У формі одразу видно «5 робочих днів · 40 год» і попередження (менше ніж за 2 тижні, більше за залишок).
- **Погодження:** запити бачить і вирішує людина з позначкою «Погоджує відпустки» (Ілля) і admin. Відхилити можна лише з коментарем. Сповіщення приходять у дзвіночок обом сторонам.
- **«Внести в ClickUp»:** погоджене, але ще не затрекане. Погоджувач вносить години в ClickUp (кнопка відкриває задачу людини) і тисне «Внесено».
- **Баланс команди** для погоджувача; позначка, якщо задачу людини в ClickUp не знайдено.
- **Свята компанії** (admin): список днів, які не віднімаються з відпустки.
- **Адмінка:** «Працює з», «Пошта в ClickUp» (якщо інша, ніж для входу), власні ліміти, «Погоджує відпустки».
- Slack не підключаємо.

## Кроки (по порядку)

1. **Supabase → SQL Editor:** встав вміст `013_leave.txt` і запусти. Має бути «Success. No rows returned».
2. **Токен ClickUp:** ClickUp → аватар → Settings → **Apps** → API Token → Generate. Скопіюй (починається з `pk_`).
   Supabase → **Edge Functions → Secrets** → Add new secret: name `CLICKUP_TOKEN`, value — токен. **Токен у чат не надсилай.**
3. **Функція:** Supabase → **Edge Functions → Deploy a new function → Via Editor**. Назва `leave-sync`. Встав увесь вміст `leave-sync.txt` (той самий код, що `index.ts`) замість прикладу → **Deploy**. «Verify JWT» лиши ввімкненим.
4. **GitHub:** завантаж файли з таблиці → Releases → тег **`v0.13.0`** → Publish.
5. Напиши «тег є». Я звірю файли, переключу Head, опублікую сайт і перевірю.
6. **Після публікації (Адмінка):**
   - Іллі — «Погоджує відпустки»;
   - кожному — «Працює з» (для ліміту лікарняних);
   - якщо на `/leave` у «Баланс команди» є «Немає задачі в ClickUp» — впиши людині «Пошту в ClickUp»;
   - на `/leave` додай свята компанії.

**Webflow не публікуй до кроку 5:** нова розмітка вже в Designer.

Перевірено: міграція на локальному Postgres 16 (двічі, ролі designer / pm / погоджувач), функція на моках ClickUp і Supabase, `smoke`…`smoke18`.
