# v0.21.0 — Ревʼю за посиланням (як markup.io, без проксі)

У правці можна відкрити **живу сторінку сайту** і ставити піни прямо на ній: анімації, скрол і hover працюють.
Проксі не потрібен — на наші сайти ставимо маленький `review-bridge.js`, який вмикається лише всередині CRM.

## Як користуватись
1. У правці — картка **«Жива сторінка»**: встав посилання (або воно вже є з поля «Сторінка») → **Відкрити ревʼю**.
2. Повноекранний режим: ліворуч піни, праворуч сайт.
   - **Коментувати** — клік по сторінці ставить пін (кнопки й посилання сайту в цьому режимі не спрацьовують, скрол і анімації — так).
   - **Переглядати** — сайт повністю інтерактивний (меню, слайдери, переходи).
   - **1440 / 768 / 390** — ширина перегляду; велика ширина зменшується під екран (видно «1440 · 76%»). Ширина запам'ятовується в правці.
3. Пін → текст → «Зберегти пін». Номер піна — той самий, що в списку «Позначки» на сторінці правки.
4. Клік по номеру в списку прокручує сайт до піна; клік по піну на сайті підсвічує його в списку. Готово / Повернути / Видалити — як для скрінів.
5. Піни прив'язані до ширини: на 390 видно лише мобільні, решта — «На інших ширинах: 1440 · 3» (клік перемикає).
6. Перейшли в «Переглядати» на іншу сторінку сайту — CRM попередить і вимкне «Коментувати», поки не повернешся.
7. Посилання `/feedback-item?id=…#review` відкриває правку одразу в режимі ревʼю. Esc — закрити.

Якщо на сайті немає мосту або сайт не дозволяє вбудовування — через 8 с з'явиться пояснення і посилання «Відкрити в новій вкладці»; скріни з пінами працюють як раніше.

## Що поставити
- **SQL:** `023_url_review.txt` → Supabase → SQL Editor → Run (ідемпотентна, лише структура).
  Без неї ревʼю відкривається, але пін не збережеться (CRM підкаже).
- **Сайти під ревʼю** (Site Settings → Custom Code → Footer):
  ```html
  <script defer src="https://cdn.jsdelivr.net/gh/GapsyStudio/gapsy-crm@v0.21.0/review-bridge.js"
          data-crm-origin="https://pet-project-gapsy.webflow.io"></script>
  ```
  Для сайту, де скрол зроблено трансформом обгортки (SmoothScroll.js), додай `data-crm-scroll-root=".назва-обгортки"`.
  Коли CRM переїде на свій домен — допиши його в `data-crm-origin` через кому.

## Безпека
- Міст інертний: без iframe і без `?crm-review=1` нічого не робить; відвідувачі сайту його не помічають.
- Міст говорить лише з origin із `data-crm-origin` і лише з батьківським вікном; CRM приймає повідомлення лише від вікна свого iframe і лише з origin сторінки з правки. Перевірено тестом (фейкові піни з вкладеного чужого iframe відкидаються; CRM на недозволеному origin не отримує відповіді).
- iframe у sandbox без `allow-top-navigation`: сайт не може перекинути CRM на іншу адресу.
- RLS не змінювався: ревʼю лише для команди.
