# v0.24.0 — без задач ClickUp на Головній

Щоб інформація не дублювалась із ClickUp:
- Прибрано блок **«Мої задачі в ClickUp»** з Головної для всіх ролей.
- У блоці **«Сьогодні»** більше немає рядків ClickUp (прострочені задачі).
- CRM більше не викликає Edge Function `my-tasks`.

Що **не** змінилось: баланс відпусток і «Внести в ClickUp» у Відпустках працюють як раніше (це не задачі, а години відпусток; функція `leave-sync`).

Код блоку лишився в `dashboard.js` — повернути можна одним рядком у ORDER.

Після релізу за бажанням: у Supabase → Edge Functions функцію `my-tasks` можна видалити (секрет `CLICKUP_HIDE` теж). Токен ClickUp **не видаляти** — його використовує `leave-sync`.

Файли: `modules/dashboard.js`, `crm-core.js` (версія), `test/smoke22.js`. SQL і стилі без змін.
